# CineMundo 🎬

## Descripción

CineMundo es un portal web de películas y series que permite consultar contenido popular y buscar títulos mediante la API de The Movie Database (TMDB).

## Características

- Visualización de películas populares.
- Consulta de series populares.
- Búsqueda de películas y series por nombre.
- Presentación de pósteres, calificaciones y fechas de estreno.
- Diseño adaptable a diferentes tamaños de pantalla.

## Tecnologías utilizadas

- HTML: estructura de la página web.
- CSS: diseño y estilos.
- JavaScript: lógica e interacción con la API.
- TMDB API: obtención de información sobre películas y series.

## Requisitos

- Un navegador web actualizado.
- Una clave de API de TMDB.
- Visual Studio Code (recomendado).
- La extensión Live Server (recomendada para ejecutar el proyecto).

La información de películas y series se obtiene mediante [The Movie Database (TMDB)](https://www.themoviedb.org/).
